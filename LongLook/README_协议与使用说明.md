# LongLook — 龙芯巡检系统 WiFi/TCP 监控前端

PC 端 Qt/C++ 桌面程序，作 **TCP 客户端**经 WiFi 连接龙芯 2K0300，**模块化**显示巡检系统的
各类传感器数据、视频、热成像，并可下发执行/联动控制命令。

> 系统背景见 `资料文件/开题报告初版.docx`：《基于龙芯与STM32双主控的智能巡检系统》，
> 含环境感知、运动控制、视觉分析、执行联动、交互通信 五大模块。本程序对应其中的「PC 上位机监控软件」。

```
┌─────────────┐   WiFi / TCP    ┌──────────────────────────────────────┐
│ 龙芯 2K0300  │ ───────────────▶│  LongLook 监控前端                    │
│ (TCP 服务端) │  传感器/视频/    │  环境·运动·视觉卡片 │ 视频 │ 热成像   │
│             │  热成像 / 命令   │  执行联动控制 │ 风险徽章 │ 日志报警  │
└─────────────┘ ◀───────────────└──────────────────────────────────────┘
```

## 一、界面（模块化）

- **顶栏**：标题 + 龙芯 IP/端口/连接/断开/状态 + **风险等级徽章**（安全/注意/警告/危险，颜色随级别）。
- **左列卡片**：
  - 🌫 环境感知：温度、湿度、烟雾/可燃气体、气压、超声波距离。
  - ⚙ 运动状态：编码器1/2、左右轮速度、转向舵机、电池电压、工作模式、故障标志。
  - 👁 视觉与风险：风险等级、火焰识别、烟雾识别、气体报警。
  - 📡 链路：遥测帧率、系统时间。
- **中**：🎥 视频区（高清摄像头，等比缩放 + 分辨率/FPS 叠加）。
- **右上**：🌡 热成像区（红外测温，伪彩 + 自动温标量程）。
- **右下**：🔧 执行与联动控制：风扇 / 蜂鸣器 / 继电器 / LED 开关、工作模式切换、⛔ 紧急停止。
- **底**：日志 / 报警。

界面为暗色监控主题，可整体缩放；命令行可自动连接：`LongLook.exe 127.0.0.1:8080`。

## 二、网络帧协议 (v2)

TCP 流式，长度前缀（TCP 已保证可靠，故不加 CRC）：

```
┌──────┬──────┬────────────┬───────────────┐
│ 0xA5 │ TYPE │ LEN(4B LE) │ PAYLOAD(LEN B) │
└──────┴──────┴────────────┴───────────────┘
```

| TYPE | 方向 | 含义 | PAYLOAD |
|------|------|------|---------|
| `0x01` | 龙芯→前端 | 综合传感器遥测 | 40 字节（见下，**小端**，解析端容忍变长）|
| `0x10` | 龙芯→前端 | 视频帧 | JPEG/PNG 字节流 |
| `0x20` | 龙芯→前端 | 热成像帧 | `uint16 w, uint16 h` + `w*h` 个 `int16` 温度(0.01°C) |
| `0x30` | 龙芯→前端 | 文本/日志 | UTF-8 |
| `0x40` | 前端→龙芯 | 控制命令 | `[cmdId u8][value u8]` |

### 传感器遥测 (0x01) — 40 字节，小端
| 偏移 | 大小 | 字段 | 说明 |
|----|----|------|------|
| 0  | 4 | timestamp_ms | uint32 系统tick |
| 4  | 2 | temperature  | int16 0.1°C (DHT22) |
| 6  | 2 | humidity     | uint16 0.1% (DHT22) |
| 8  | 2 | gas_ppm      | uint16 (MQ-2) |
| 10 | 4 | pressure_pa  | uint32 Pa (BMP280) |
| 14 | 2 | distance_cm  | uint16 (HC-SR04) |
| 16 | 4 | encoder1     | int32 |
| 20 | 4 | encoder2     | int32 |
| 24 | 2 | speed_L      | int16 |
| 26 | 2 | speed_R      | int16 |
| 28 | 2 | servo_us     | uint16 |
| 30 | 2 | voltage_mV   | uint16 |
| 32 | 1 | mode         | uint8 (0手动/1自动/2避障/3巡检) |
| 33 | 1 | fault        | uint8 |
| 34 | 1 | risk_level   | uint8 (0安全/1注意/2警告/3危险) |
| 35 | 1 | flags        | uint8 (bit0火焰 bit1烟雾 bit2气体报警) |
| 36 | 1 | fan          | uint8 风扇状态 |
| 37 | 1 | buzzer       | uint8 蜂鸣器状态 |
| 38 | 1 | relay        | uint8 继电器状态 |
| 39 | 1 | led          | uint8 LED状态 |

> 解析端逐字段读取、越界取 0：龙芯端**只发前 N 字节也能用**（如暂无视觉/联动时只发前 34 字节），后续扩展字段也不破坏旧前端。

### 控制命令 (0x40) — cmdId / value
| cmdId | 含义 | value |
|----|------|------|
| 0x01 | 风扇 | 0关/1开 |
| 0x02 | 蜂鸣器 | 0关/1开 |
| 0x03 | 继电器 | 0断/1通 |
| 0x04 | LED | 0灭/1亮 |
| 0x05 | 模式 | 0手动/1自动/2避障/3巡检 |
| 0x06 | 急停 | 1 |

## 三、龙芯端发送/接收参考（Python，可当测试服务器）

`scratchpad/loong_sim2.py`（仓库随附思路）即一个完整示例：发送 40 字节传感器帧 + 热成像帧，
并非阻塞接收 0x40 控制命令。核心打包：

```python
def frame(t, payload): return bytes([0xA5, t]) + struct.pack("<I", len(payload)) + payload
# 传感器 40 字节
pl = struct.pack("<IhHHIHiihhHHBBBBBBBB",
    ts, temp01c, humi01, gas, pres_pa, dist,
    enc1, enc2, spdL, spdR, servo, volt,
    mode, fault, risk, flags, fan, buzzer, relay, led)
sock.sendall(frame(0x01, pl))
# 视频: sock.sendall(frame(0x10, open('x.jpg','rb').read()))
# 热成像: struct.pack("<HH", w, h) + b''.join(struct.pack("<h", t_001c) for ...)
```

真实龙芯端用 C/Python 按此 `frame()` 打包即可，前端无需改动。

## 四、构建与运行

- **运行（Windows）**：双击 `启动LongLook.bat`（已随附 Qt 运行库 + imageformats/qjpeg 用于视频解码）。
- **源码构建**：Qt 5.15 + MinGW，`qmake LongLook.pro && mingw32-make`。仅依赖 `QtWidgets + QtNetwork`。
- **龙芯/Linux 上运行前端**：装 Qt5(LoongArch) → `qmake && make` 即可，无平台相关代码。

## 五、后续完善方向

- 视频：接真实摄像头流（MJPEG/RTSP→JPEG 帧下发，或 H.264 解码）+ 叠加 YOLO 识别框。
- 热成像：对接真实热像仪分辨率与点测温、调色板切换、温度网格。
- 数据：速度/温湿度/气体 时序曲线图（QtCharts）、历史数据存库与查询。
- 报警：声光提示、报警日志独立面板与导出、风险升级弹窗。
- 通信：断线自动重连、MQTT 通道（开题报告提到 TCP/MQTT）、命令 ACK。
