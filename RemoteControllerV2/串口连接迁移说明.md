# 上位机：蓝牙 → 串口直连 迁移说明

**日期**：2026-06-29
**目标**：放弃不可控的 BLE，改为**串口(UART)直连**下发指令；保留上位机全部功能；并可迁移到**龙芯 2K0300**（Linux）。当前为验证阶段。

---

## 一、核心结论：串口链路本就存在，本次为“正名 + 去 BLE + 跨平台兜底”

关键发现：原工程的 **`BluetoothManager` 其实是一个 `QSerialPort` 封装**（“经典蓝牙”=串口 SPP），“蓝牙连接”标签页本身就是**串口连接 UI**（端口下拉 `comboBluetoothPorts` + 波特率 `comboBaudRate` + 连接/断开/扫描 + 日志），且收发链路早已接好：

- 发送：`onTimerUpdate()` → `sendData()` → `m_bluetoothManager->sendData()`（串口 `write`）
- 接收：串口 `readyRead` → `BluetoothManager::dataReceived` → `processTelemetryBytes()`（解析遥测）
- 端口枚举：`QSerialPortInfo::availablePorts()`（**跨平台**：Windows 列 `COMx`，龙芯/Linux 列 `/dev/ttyUSB*`、`/dev/ttyS*`）

所以协议帧、控制逻辑、遥测显示**全部沿用、无需改动**。F4 端不关心字节来自 BT 模块还是 USB-TTL 直连。

## 二、本次改动

| 文件 | 改动 |
|------|------|
| `mainwindow.ui` | 标签页标题 `📡 蓝牙连接` → **`🔌 串口连接`**；标题栏文字 → `串口连接 (USB-TTL / 龙芯 2K0300 UART)` |
| `mainwindow.cpp` | 不再创建塞在该页里的 **BLE 面板**（`createBLEControlPanel()` 及其日志按钮块移除），该页现仅保留纯串口控件；启动日志/状态栏/失败提示等文案由“蓝牙/HC-05”改为“串口” |
| `RemoteController.pro` | `LIBS += -lXinput` → **`win32: LIBS += -lXinput`**（XInput 仅 Windows）；注释说明龙芯构建可去 `bluetooth` 模块与 `bledevicemanager.*` |
| `joystickreader.h/.cpp` | XInput/`windows.h` 代码加 **`#ifdef Q_OS_WIN`** 守卫，非 Windows 下编译为空实现（龙芯改用模拟手柄/键盘） |

> 说明：BLE 相关代码（`bledevicemanager.*`、`BleManager`）暂保留在工程中但**不再接入 UI、不参与运行**，以保证当前 Windows 验证构建零风险通过。彻底删除留到龙芯构建时做（见第四节）。

编译：`qmake + mingw32-make`（Qt 5.15.2 / MinGW 8.1）通过，**0 错误**；已重建并部署 `RemoteController_v2.exe`。

## 三、验证用法（Windows）

1. 用 **USB-TTL 适配器**直连 F4 的 USART3（旁路蓝牙模块）：
   - USB-TTL **TX → F4 PB11**（USART3_RX）
   - USB-TTL **RX → F4 PB10**（USART3_TX）
   - **GND ↔ GND**
   - 电平 **3.3V**，波特率 **115200**（8N1）
2. 运行 `启动遥控手柄.bat` → 切到 **🔌 串口连接** 标签页 → 选中 USB-TTL 的 COM 口 → 波特率 115200 → **连接**。
3. 回主控制页：摇杆/模拟按钮/键盘操作 → F4 调试串口应出现 `RX遥控: speed=.. steer=..`、`ok` 增长、OLED `BT Connected`，电机/转向随动；松手 ~0.5s 安全停车。
4. 遥测：F4 回传帧经串口返回，上位机遥测面板显示速度/转向/模式/帧计数。

## 四、迁移到龙芯 2K0300（Linux）步骤

1. 在龙芯上装 **Qt5（LoongArch 版）** + `qtserialport`；用 `qmake && make` 构建。
2. 串口枚举/连接已跨平台，端口会显示为 `/dev/ttyUSB0` 等；连接逻辑 `displayName.split(" ").first()` 对 `/dev/ttyXXX` 同样正确。
3. **物理手柄(XInput)仅 Windows**：龙芯上用界面“模拟手柄”按钮或键盘控制（已用 `Q_OS_WIN` 守卫，Linux 可编译）。
4. 若龙芯 Qt **不含 QtBluetooth**：从 `RemoteController.pro` 删除 `bluetooth` 模块、并从 `SOURCES/HEADERS` 移除 `bledevicemanager.*`；同时删除 `mainwindow` 中对 `BleManager`/`onBLE*` 的引用（这些已不参与运行，删除即可）。需要我做这步“彻底去 BLE”可继续。
5. 串口权限：Linux 下普通用户访问 `/dev/ttyUSB*` 需加入 `dialout` 组（`sudo usermod -aG dialout $USER`）。

## 五、数据帧（不变）

7 字节：`[0]=0xAA` `[1..2]=speed(大端)` `[3..4]=steering(大端)` `[5]=mode(命令 bit7=0)` `[6]=XOR(byte0~5)`。与 F4 `protocol.c` 完全一致。
