# 循迹、2000 档与 MLML 热点升级验证

日期：2026-10-10。目标版本：PatrolSystem 1.25.4。龙芯项目源码位于 WSL Ubuntu `/opPJ/PatrolSystem`，Windows 工作目录为 `F:\projectForXN\NGFXM`。

本次修复三项问题：循迹使用不合适的固定阈值导致线路识别不稳定；全系统速度上限需要提高至 2000；龙芯启动联网需要从 B410 切换到手机热点 MLML。升级前的 1.25.3 源码已单独保存，现有温湿度、热像和电机保护行为继续保留。

## 循迹修复及使用步骤

三路 TCRT5000 使用各自的黑白采样范围生成阈值，避免三个探头基线不同却共用固定阈值。当前使用模拟量 AO，接入 ADC1 的 PC0、PC1、PC3；修改宏不能替代实际接线和 ADC 配置。

| 项目 | 当前实现 |
| --- | --- |
| 采样 | 以真实时间间隔采样，最小间隔 5ms；多个任务同一时刻读取不会加速去抖 |
| 抗毛刺 | 每路最近 3 次采样取中值；获得 3 个真实样本前不学习端点 |
| 端点确认 | 新端点需连续 3 次确认，并与原端点相差超过 20 ADC 单位 |
| 有效标定 | 每路观察到至少 400 ADC 单位的跨度；三路全部就绪才允许循迹运动 |
| 迟滞 | 离线阈值取跨度 40%，压线阈值取 60%；迟滞带内保持原状态 |
| 状态去抖 | 连续 2 次越过同一阈值才翻转 |
| 默认极性 | 黑线读数高、底色读数低；现场反极性需使用对应宏或两点标定接口 |
| 长时间丢线 | 不遗忘已采到的底色范围，避免把底色逐渐重新解释成线路 |

每次重新上电后，保持车辆停车，手动横扫线路和底色，让左、中、右探头分别经过两种表面，再将中间探头对准线路。三路全部完成标定前，循迹模式保持停车，上位机显示“循迹待标定，已停车”；遥控模式显示“循迹待标定（遥控可用）”。标定数据当前不写入掉电保存区，不能将一次标定当成永久完成。

若完成横扫仍未就绪，应查看 `[LINE_ADC]` 日志中的原始读数、ON/OFF 阈值和 readyMask，核对探头高度、表面反差及接线。readyMask=7 表示三路全部就绪。软件提供 `LineTrack_SetCalibration(background, line)` 两点标定接口，可分别处理每路极性；本次没有新增远程两点标定命令。

巡检保护同时修复：从未见过正常线路时不会盲目前进；全压线需持续 50ms 才认作路口，并须此前见过普通线路；短时丢线仅以不超过 220 档的速度按最近方向修正，800ms 后停车；放行路口后的离点和找线阶段超过 3000ms 仍未完成也停车。ADC 停止采样时清除当前压线状态并禁止循迹运动，恢复采样不重置已取得的正常标定范围。

## 全系统速度配置

速度设置统一为 **100～2000、步进 100，共 20 档**，默认自动巡检 **500**。档位编码为 `gear=0..19`、`level=100+100×gear`，默认 gear=4。零表示停车，不属于配置档位。

落实范围包括 LongLook 主界面和遥控面板、手柄数值输入、键盘高速预设、LB/RB 加减档、摇杆、蓝牙和 WiFi 发送、龙芯配置持久化及 CAN/UART 转发、F4 本地按键和全部运动模式。速度指令允许 ±2000，转向仍限制在 ±1000；两个范围分别限幅，不能再共用 1000 上限。非法档位 gear≥20 或不符合步进的配置不接受。

| 配置档位 | 编码器目标 |
| --- | --- |
| 100 | 1200 CPS |
| 500（默认） | 6000 CPS |
| 1000 | 12000 CPS |
| 1500 | 18000 CPS |
| 2000（最高） | 24000 CPS |

档位乘以 12 得到编码器单边沿脉冲/秒目标，CPS 不等于 PWM、轴 RPM 或地面速度。保留 PWM 硬上限 500/1000，以及 PWM 载波和方向 PH 的 1000 级分辨率；编码器 1500 counts/17ms 的异常增量保护和伺服 1500µs 中位不随档位上限修改。

保留加速 2500 CPS/s、降档减速 4000 CPS/s、加速度变化 8000 CPS/s²，以及 PWM 上升/下降 150/400 单位每秒的限制。转向越大，速度目标连续下降，满转角最高 1800 CPS；高速打舵按目标和两轮实际反馈渐进放开转角。反馈诊断写入 16 位字段前饱和至 -32768～32767，内部控制仍保留完整浮点反馈，避免超速时显示回绕。

零速度立即关闭电机输出；反向前等待滑行与低速条件。采样、编码器、反向反馈、堵转和超速异常触发停车并锁存，零指令解除锁存。提高档位不保证任何负载下都达到目标；达到 PWM 上限时，实际速度受供电、机械阻力及可用转矩约束，不能为了达到数值取消输出保护。

## MLML 热点及龙芯启动

当前启动联网配置从 B410 改为 **MLML**，使用 DHCP。龙芯 1.25.4 已实际自动启动并连接 MLML，当前地址为 **10.52.36.140**，`patrol.service` 为 active，`NRestarts=0`。上位机连接该地址的 TCP 8080 端口；手机热点重新启动后地址可能变化，应以实际租约为准。

热点密码通过设备本地文件提供，文档和仓库不记录密码正文。设备网络配置、密码文件和生成的 wpa_supplicant 配置均使用 root 的 0600 权限。联网配置与原网络配置备份分开保存，防止把旧 B410 设置误当成当前启动配置。
