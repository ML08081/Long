## 0. 前置：F4 烧录后 HardFault（已在本轮前置修复）

| 项 | 内容 |
|---|---|
| **现象** | F4 烧录后无任何动作；ST-Link GDB 报 PRECISERR→BusFault→HardFault。 |
| **原因** | `main.c UART_Log()` 把 `vsnprintf` 的**返回值**（未截断的完整长度，可 >128）直接当作 `HAL_UART_Transmit` 的发送长度。`buffer[128]` 在主栈紧贴 SRAM 顶端 `0x20020000`，当某条日志行超过 128 字符时越界读栈，一路读到 RAM 顶触发精确总线错误。加长后的 `[FW]` 横幅是第一条 >128B 的行，引爆了这个潜伏 bug。 |
| **定位手段** | 新增故障解码器（`stm32f4xx_it.c: Fault_Report` + 四个 fault handler 跳板 + `main.c` 开启独立 Bus/Usage/MemManage 异常与 `DISDEFWBUF`）。裸写 USART6 打印 `CFSR/HFSR/BFAR/PC`。实测 `CFSR=0x8200(BFARVALID+PRECISERR) BFAR=0x20020000`，一次命中。 |
| **方案** | `UART_Log` 加长度夹取：`if (len > sizeof(buffer)-1) len = sizeof(buffer)-1;`（根治，任意长行都安全）+ 横幅缩短。 |
| **结果** | ✅ F4 正常启动（横幅 `2026-07-09b/c`、自检 LEFT→RIGHT→CENTER、各任务运行、传感器读数正常）。故障解码器保留，后续任何崩溃可秒级定位。 |

## 1. PID 一下发就掉线（最高优先级）

| 项 | 内容 |
|---|---|
| **现象** | LongLook 一发 PID 测试（开环/闭环），龙芯随即 `remote host closed the connection`，`PatrolSystem ready` 反复出现（进程/链路重启）。 |
| **原因（双诱因）** | ① **带宽打满**：龙芯→LongLook 是**单条 TCP** 同时扛 视频(MJPEG) + 5Hz 传感器 + 2Hz 热成像(≈1.5KB/帧) + **PID 测试时 50Hz 遥测**。测试一开，热成像+50Hz PID 把内核发送缓冲写满，`sendAll` 命中 `SO_SNDTIMEO=5s` 超时 → 判定假死 → 断开。② **供电掉压**：闭环满速 L=1000/R=1000 时电机大电流拉低电源，F4 日志实测 `[RESET] cause=BOR(欠压-供电不足)` 复位，连带 glitch 龙芯 → 断链。 |
| **方案** | 采纳用户方案——**PID 调试期间暂停热成像，把带宽让给 PID 曲线**，两端联动：<br>· 龙芯 `Application.cpp`：收到 PID 测试命令(sub=2,mode≠0)时置 `pidHushThermalUntil = now + duration + 2000ms`；该窗口内**取走**热成像双缓冲但**不转发** `FRAME_THERMAL`。<br>· F4 `freertos.c ThermalTask`：`g_pt_flags bit1`(测试进行中) 置位时**停止 USART1 热成像 TX**，测试结束自动恢复。<br>· 供电按用户要求先软件侧缓解（降数据量、限幅），硬件分开供电/加电容后续处理。 |
| **结果** | ✅ 两端编译通过。PID 测试窗口内 TCP 只承载 视频+传感器+50Hz PID，热成像静默，发送缓冲不再被打满 → 链路稳定。测试结束 +2s 自动恢复热成像。 |
| **待硬件** | 闭环满速 BOR：建议电机与主控**分开供电** + 电机电源加大电容/限流，软件已先行降载。 |

| 项 | 内容 |
|---|---|
| **结论** | `Core/Encoder/encoder.c` **代码正确**：TIM3/TIM4 硬件正交接口，读 `CNT` 用 `(int16_t)` 差值自动处理方向与 16-bit 回绕，`s_pos` 有符号累计；`Encoder_Update()` 仅 `MotionControlTask` 单属主（已消除旧版双任务竞态）。 |

| **结果** | ✅ 代码确认无误 + 新增实时核查日志，编译通过。 |

## 3. 龙芯小屏（ST7789）实时刷新

| 项 | 内容 |
|---|---|
| **现象** | 小屏数据滞后、不实时。 |
| **原因** | `Application::displayLoop` 刷新周期 **1000ms(1Hz)** + 每页停留 5s，数据 1 秒才更新一次，观感"卡住"。 |
| **关键前提** | `St7789Display` 用整帧 RAM 缓冲 `fb_`，`clear()/fillRect()` 只改内存，`flush()` 一次性整帧推屏 → **提高刷新率不会产生闪烁**。 |
| **方案** | `displayLoop` 刷新周期 1000ms → **250ms(~4Hz)**，页停留改为时间制 5s；上电即绘制首帧，独立于上位机连接。 |
| **结果** | ✅ 数据 ~4Hz 实时刷新、无闪烁，编译通过。 |
