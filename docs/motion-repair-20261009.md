# 1.25.2 电机低速修复与悬空验证

本次在用户确认驱动轮悬空、动力电源开启后完成 F4 和龙芯更新。目标是降低巡检速度、统一速度指令与反馈、避免反馈接错后越调越快。未进行落地巡检或路线验收。

## 实机确认的原因

1. 旧指令按 `档位/1000 × 1100 脉冲/17ms` 换算，100 档实际目标约 6471 脉冲/秒；500 档约 32353 脉冲/秒。再叠加非零 PWM 至少 200 的补偿，低档也偏快。
2. 当前接线与历史注释不同。单轮测试只驱动 Motor1 时 ENC2 增长，ENC1 不增长。因此闭环应为 Motor1→ENC2、Motor2→ENC1；原同编号配对会调节另一侧电机。
3. 当前 DIR 极性与历史值相反。实测正 PWM 对应 ENC1 DIR=0、ENC2 DIR=1，已修正；倒车实测确认两路反馈为负。
4. 固定17ms计算、复制异常采样的旧增量、实时任务大量串口打印，会造成速度误判和控制节拍抖动。
5. 避障强制零速被误当作操作者释放指令，连续前进可能产生虚假的解锁边沿，导致反复停走。已改为只用新收到的操纵指令或物理按键判断边沿。

## 当前控制约定

- 100～1000、步进50、默认500，单位统一为**编码器上升沿脉冲/秒**。不是 PWM、RPM 或地面线速度，尚未确认轮径和传动比。
- 遥控、按钮、循迹及巡检的最终电机控制共用同一速度上限、独立两轮闭环和起步轨迹。全转向时目标最高150脉冲/秒；中间角度连续降低上限。
- 实际采样时间使用 DWT 计数，绝对周期调度；输出缓升，不使用反向 PWM 制动来纠正超速。
- 输出绝对上限为120/1000，即12%占空比。当前台架常用输出约4%～6%；保留可由反馈抵消的缓升摩擦前馈，取消200的硬最低输出。
- 换向先清零，至少等待150ms，并等待两轮反馈低于30脉冲/秒。零指令立即清零输出。
- 采样时间、编码器增量、反馈方向、堵转、持续超速异常会锁存并停止两轮；零速指令清除锁存。上位机收到运动故障显示“电机反馈异常，已停机”。
- 左右轮显示已修正：ENC2为左轮、ENC1为右轮。上位机及遥控手柄显示明确速度单位；实际使用的 Qt Creator Debug EXE 和日常 Release EXE 均已更新。
- 上位机直接显示避障锁定及“松开再前推两次”的操作提示，运动闭环故障优先显示。实机停止状态可能保留避障锁，前方净空后仍需真实操作确认，不自动解除。
- 急停后可重新选择当前“遥控模式”恢复控制；仅用户选择发模式命令，设备模式回显不会意外解除急停。

## 悬空实测结果

各段12秒；下表为最后3秒 CAN 控制器反馈的平均值，顺序为右轮/左轮。

| 指令 | 最终目标 | 平均反馈（脉冲/秒） | 峰值PWM |
| --- | --- | --- | --- |
| 前进100 | 100 | 104.8 / 115.4 | 55/1000 |
| 前进500 | 500 | 508.6 / 480.8 | 57/1000 |
| 后退500 | -500 | -499.8 / -499.9 | 58/1000 |
| 前进1000 | 1000 | 1003.4 / 1015.3 | 56/1000 |
| 1000档、满转向 | 150 | 182.1 / 173.7 | 57/1000 |

采样间隔最高19ms，各段结束 PWM 均归零。故障诊断阶段实测验证持续超速能停机。最低档仍可见静摩擦引起的瞬时速度波动，不能将平均值解释为全程恒速或已完成落地顺滑性验收。默认500档不再使用旧版本的大速度换算。

## 新增只读CAN诊断

标准ID `0x481`，DLC=8，大端有符号16位，约10Hz：

- sub=06：`[06, 目标CPS i16, 右轮CPS i16, 左轮CPS i16, 故障u8]`。
- sub=07：`[07, 右轮PWM i16, 左轮PWM i16, 间隔ms u8, 故障u8, 版本01]`。
- 故障位：1时序、2编码器、4方向、8堵转、16持续超速。网络传感器故障位64表示运动闭环故障。
- 单轮映射诊断构建仅用于悬空测量；最终源码及固件不包含单轮强制输出分支。

详细记录在 Windows `motion-fix-20261009/`，WSL源码为 `/opPJ/PatrolSystem`。悬空测试脚本含实际驱动命令，只能在再次确认轮子悬空后执行；普通离线回归不打开硬件。
